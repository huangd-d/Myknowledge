# 这个知识库怎么用

这个站点没有后台，也没有数据库。页面启动时用 `import.meta.glob` 把仓库里的 Markdown 全部读进来，所以在仓库里加一个 `.md` 文件，刷新浏览器就能看到。

## 放哪里

两个目录都会被收录：

- `knowledge/**/*.md`：个人笔记，分类统一显示为「个人笔记」。
- `skills/<技能名>/**/*.md`：技能文档，分类名就是 `<技能名>`。

分类来自目录，不来自 frontmatter，所以不要为了分类去建嵌套三层的目录，一个技能一个目录就够了。

## 写什么

frontmatter 是可选的，只有两个字段有意义：

```md
---
title: 显示用的标题
description: 列表页的一句话摘要
---
```

不写的话，标题取第一个 `#` 标题，摘要在正文第一段里截。正文支持的语法就是本页用到的这些：标题、列表、引用、代码块、表格、链接、粗体斜体。

## 检索怎么生效

搜索框会把标题、摘要、分类和**整篇正文**拼起来做不区分大小写匹配，纯前端内存过滤，几千篇以内都不需要索引。

## 一个建议

每篇笔记尽量只回答一个问题，并且把结论写在最前面。三个月后你回来找的，是结论，不是推导过程。
